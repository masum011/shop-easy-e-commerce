# Shop Easy

A simple e-commerce application built with React, TypeScript, Vite, and Tailwind CSS.

## Features

* Product listing
* Product details page
* Shopping cart
* Category filtering
* Product sorting
* Local Storage persistence
* Lazy-loaded routes

## Tech Stack

* React
* TypeScript
* React Router DOM
* Tailwind CSS
* Vite
* Context API
* useReducer
